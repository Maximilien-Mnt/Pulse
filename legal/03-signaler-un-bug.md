# Comment signaler un problème ?

> **En résumé** — Cette page explique comment signaler un problème technique (bug) sur Pulse : où cliquer, quelles informations donner, et sous quel délai nous traitons votre signalement. Pour signaler un contenu ou un utilisateur, ou pour toute autre demande, utilisez les procédures dédiées mentionnées ci-dessous.

**Application :** Pulse
**Date d'entrée en vigueur :** 15 août 2026
**Dernière mise à jour :** 7 août 2026
**Version du document :** 1.0

---

## 1. Que signaler ici

Utilisez cette procédure uniquement pour un **problème technique** : plantage de l'application, fonctionnalité qui ne fonctionne pas, écran bloqué, erreur d'affichage, etc.

Ne signalez pas ici :
- un contenu ou un profil qui enfreint nos règles → utilisez le bouton **Signaler**, disponible depuis le menu d'options d'un post ou d'un profil (voir notre **Politique de contenu et de modération**) ;
- une question, une suggestion ou une demande générale → contactez le **Support** (voir nos coordonnées ci-dessous).

## 2. Comment signaler un bug

Depuis l'application :

1. Ouvrir les **paramètres** de l'application ;
2. Appuyer sur **Signaler un bug** dans la section Support ;
3. Décrire le problème rencontré ;
4. Consulter les informations qui seront collectées automatiquement (appareil, système, version, etc.) ;
5. Appuyer sur **Envoyer**.

Vous pouvez aussi nous écrire directement à **maximilien.montant@gmail.com** en indiquant « Bug » dans l'objet du message.

## 3. Informations à fournir

Pour que nous puissions comprendre et corriger le problème rapidement, merci d'indiquer autant que possible :
- une description claire du problème ;
- les étapes pour reproduire le problème ;
- une capture d'écran ou une vidéo, si possible (par mail);
- le modèle de votre appareil et la version de l'application (visible dans les paramètres) ;
- le moment approximatif où le problème est survenu.

## 4. Délai de traitement

Nous traitons les signalements de bugs dans un délai allant de **quelques jours à quelques semaines**, selon leur nature et leur gravité. Les problèmes liés à la sécurité sont traités en priorité.

## 5. Ce qui n'est pas couvert ici

- Les signalements de contenu ou de comptes → voir notre **Politique de contenu et de modération**.
- Les demandes générales (suggestions, questions) → voir le Support ci-dessous.
